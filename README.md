# 🎓 EduMate

An AI-powered study tool that lets you upload PDF documents and interact with them through summarization, topic explanation, quiz generation, text Q&A, and voice Q&A — in both **English and Bangla (বাংলা)**.

---
 
## Features

- **📄 PDF Upload** — Drag & drop or browse to upload any PDF study material
- **📝 Summarize** — Generate a comprehensive summary of the uploaded document
- **💡 Explain Topics** — Get simple, student-friendly explanations of any topic from the document
- **🧠 Interactive Quiz** — Auto-generate MCQ quizzes with progress tracking, scoring, and instant answer feedback
- **💬 Text Q&A** — Ask any question and get answers grounded in the document
- **🎙 Voice Q&A** — Record your question, get a spoken answer back (WAV-based, no ffmpeg needed)
- **🌐 Language Switch** — Toggle between **English** and **বাংলা** for all features including summaries, explanations, quizzes, Q&A, and voice

---

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Backend | Python, FastAPI |
| AI / LLM | Gemini 2.0 Flash via [OpenRouter](https://openrouter.ai) |
| Embeddings | Google Gemini (`gemini-embedding-001`) |
| RAG Pipeline | LangChain + FAISS |
| PDF Parsing | PyPDF |
| Speech-to-Text | Google Speech Recognition (free, no key needed) |
| Text-to-Speech | gTTS (supports English & Bangla) |
| Frontend | HTML + Tailwind CSS + Vanilla JS |

## Setup & Installation

### 1. Clone or download the project

```bash
cd EduMate
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Add your API keys

Open `rag.py` and replace the placeholder values:

```python
OPENROUTER_API_KEY = "your_openrouter_api_key"
GEMINI_API_KEY     = "your_gemini_api_key"
```

- Get your **OpenRouter** key → [openrouter.ai/keys](https://openrouter.ai/keys)
- Get your **Gemini** key → [aistudio.google.com/apikey](https://aistudio.google.com/apikey)

### 4. Run the server

```bash
python main.py
```

### 5. Open the app

```
http://localhost:8000
```

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/upload` | Upload a PDF (`form-data`: `session_id`, `file`) |
| `GET` | `/summarize/{session_id}?lang=en` | Summarize the document (`lang=en` or `lang=bn`) |
| `POST` | `/explain/{session_id}` | Explain a topic `{"topic": "...", "lang": "en"}` |
| `GET` | `/quiz/{session_id}?num_questions=5&lang=en` | Generate MCQ quiz |
| `POST` | `/ask/{session_id}` | Ask a question `{"question": "...", "lang": "en"}` |
| `POST` | `/voice/{session_id}` | Upload WAV audio + `lang` form field, get spoken answer back |

Interactive API docs available at `http://localhost:8000/docs`

## How It Works

```
PDF Upload
   │
   ▼
PyPDF (parse) → Text Chunks → Gemini Embeddings → FAISS Vector Store
                                                         │
User Query ──────────────────────────────────────────────┘
   │                                                      │
   ▼                                                      ▼
Retrieve top-4 relevant chunks ──► Gemini 2.0 Flash (via OpenRouter)
                                    + Language instruction in prompt
                                         │
                                         ▼
                              Answer / Summary / Quiz / Explanation
                              (in English or Bangla based on toggle)
```

---

## Notes

- Each browser session gets a unique `session_id` — multiple users/documents are isolated in memory
- Voice recording uses browser `AudioContext` to encode WAV directly — no ffmpeg required
- Voice STT uses Google's free Speech Recognition API — no extra key needed
- OpenRouter free tier has rate limits; the app retries automatically with exponential backoff (up to 5 attempts)
- Only PDF files are supported for upload
- Bangla responses are generated by injecting a language instruction directly into the LLM prompt
